# NOORÉ E-Commerce

Build a premium, modern Pakistani women’s fashion e-commerce website with a luxurious, elegant and editorial visual style.

## BRAND DIRECTION

Create a sophisticated fashion brand called **NOORÉ**.

Tagline:
**“Elegance in Every Thread”**

The website should feel like a premium Pakistani fashion brand — elegant, feminine, minimal and high-end. It should NOT look like a generic Shopify template or a cheap clothing store.

Target audience:

* Pakistani women
* Age 18–45
* Interested in modern Pakistani fashion
* Ready-to-wear, unstitched, embroidered collections, festive wear and accessories

The overall visual inspiration should feel similar to premium fashion brands while maintaining a clear Pakistani fashion identity.

---

# COLOR PALETTE

Use this color system throughout the website:

* Primary Deep Emerald: `#064E3B`
* Dark Emerald: `#033C2E`
* Warm Cream Background: `#F8F5ED`
* Soft Ivory: `#FFFDF8`
* Champagne Gold: `#C9A96E`
* Dark Text: `#17231F`
* Muted Text: `#66716B`
* Light Border: `#E7E1D5`

Do NOT use bright pink, purple, neon colors or overly colorful gradients.

The primary CTA buttons should use Deep Emerald with white text.

Use Champagne Gold only as a subtle accent for:

* decorative lines
* small labels
* icons
* hover states
* premium details

# DESIGN RULES

IMPORTANT:

1. Keep the website premium and minimal.
2. Do not use excessive shadows.
3. Do not use bright gradients.
4. Do not use generic stock-looking UI.
5. Do not overcrowd sections.
6. Use lots of whitespace.
7. Use Deep Emerald as the primary brand color.
8. Use Cream/Ivory as the main background.
9. Use Champagne Gold sparingly.
10. Product photography should be the visual focus.
11. Maintain consistent spacing and typography.
12. Make buttons and cards feel premium.
13. Ensure excellent mobile responsiveness.
14. Use Lucide icons or another clean icon library.
15. Use reusable components rather than duplicating UI.
16. Make the entire experience feel like a real production-ready Pakistani fashion brand.

---

# TECHNICAL REQUIREMENTS

Use:

* React
* TypeScript
* Tailwind CSS
* Responsive design
* Reusable components
* Clean component architecture
* Proper routing
* Accessible buttons and forms
* Semantic HTML
* Optimized images
* Loading states
* Empty states
* Hover/focus states

Create realistic mock product data so the website does NOT feel empty.

Important:
Every navigation page should have meaningful content. Do not create empty placeholder pages.

Build the homepage first with all sections fully populated, then create the Shop, Collection, Product Detail, Cart and other supporting pages using the same design system.

The final result should look like a **premium Pakistani women's fashion e-commerce brand**, not a generic AI-generated website.
